## Sobre mim

Transformo dados em decisões. Uso **Python, SQL e Power BI** para organizar informações, encontrar padrões e contar a história por trás dos números, e levo para a análise de dados a visão de processos que aprendi na **mecatrônica**.

Também construo sistemas completos com **Node.js**, como a ClarIA, que automatiza o atendimento de clínicas no WhatsApp.
